# DIG-23 spike: Bedrock models and Textract in Mumbai (ap-south-1)

Checked on 17 Nov 2026 with `api/scripts/spike-bedrock/run.ts`. All inputs are synthetic: the lab report is generated by `make-sample.py`, and the transcripts come from the DIG-25 spike.

## Decision

- **LLM:** Claude Opus 5 via the Bedrock inference profile **`in.anthropic.claude-opus-5`**, which routes only within India (ap-south-1 and ap-south-2), so no patient data leaves India. Chosen on 17 Nov 2026 over the newer Opus 5.5, because Opus 5.5 is available only through a `global.*` profile that may run in any region.
- **Client:** `AnthropicBedrock` from `@anthropic-ai/bedrock-sdk`, which uses the InvokeModel API. The newer Bedrock Messages endpoint ("Mantle") returns 404 for every Claude model in ap-south-1.
- **OCR:** Textract `AnalyzeDocument` with `FeatureTypes: ['TABLES']` in ap-south-1.
- **Cross-region inference:** don't use it. It is allowed only if a needed model has no `in.*` profile, only with synthetic data, and only with the decision recorded in CLAUDE.md.

This decision is recorded in `CLAUDE.md`.

**Model access:** Bedrock reports `AUTHORIZED` for the account. The first call starts an AWS Marketplace subscription for the Anthropic models, which needs a valid payment method on the AWS account (see Status).

Approximate figures; check the Bedrock pricing page for India profile rates.

- Every call must write `usage_events` (tokens, pages).
