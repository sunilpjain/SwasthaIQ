# SwasthyaIQ (स्वास्थIQ) — Arihant prototype

Monorepo for the first running SwasthyaIQ prototype: a native Android app for two doctors at Arihant Clinic, Surat, a web Admin dashboard, and the API and AWS infrastructure behind them. Synthetic patients only — **prototype, not for clinical use**.

See [CLAUDE.md](CLAUDE.md) for architecture, commands and rules. `legacy-demo/` holds the earlier Figma Make browser demo for reference.
